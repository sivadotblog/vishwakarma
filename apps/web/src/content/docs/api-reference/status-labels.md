---
title: Status Labels
description: Reference for status labels that Vishwakarma sets on GitHub issues.
---

Vishwakarma sets status labels on GitHub issues to track the progress of automated work.

| Label            | Description                                           |
| ---------------- | ----------------------------------------------------- |
| `vk:in-progress` | VK processes the issue                                |
| `vk:pr-open`     | VK delivered a draft PR                               |
| `vk:needs-info`  | VK posted questions and stopped                       |
| `vk:blocked`     | Review failed after revision cycles; VK created no PR |
