---
title: Status Labels
description: Reference for status labels set by Vishwakarma on GitHub issues.
---

Vishwakarma sets status labels on GitHub issues to track the progress of automated work.

| Label            | Meaning                                                         |
| ---------------- | --------------------------------------------------------------- |
| `vk:in-progress` | VK is working on the issue                                      |
| `vk:pr-open`     | VK delivered a draft PR                                         |
| `vk:needs-info`  | VK posted clarifying questions and stopped                      |
| `vk:blocked`     | Review still failed after the revision cycles; no PR was opened |
