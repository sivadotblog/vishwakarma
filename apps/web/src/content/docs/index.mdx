Vishwakarma is an autonomous software factory that turns GitHub issues into reviewed pull requests. Labeling an issue with `vk` hands it off to the factory to classify, plan, implement, and review before opening a draft pull request.

<CardGrid stagger>
	<Card title="How work arrives" icon="pencil">
		Label a GitHub issue with `vk` to hand work off to the factory.
	</Card>
	<Card title="What you get back" icon="document">
		Receive a reviewed draft pull request with an execution run log under
		`docs/factory/`.
	</Card>
	<Card title="Human in the loop" icon="setting">
		Maintain control over key decisions: review the draft PR, mark it ready, and
		merge.
	</Card>
</CardGrid>
