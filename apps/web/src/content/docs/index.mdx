Vishwakarma is an autonomous software factory that converts GitHub issues into reviewed pull requests. When you add the `vk` label to an issue, the factory receives the task. The factory classifies, plans, implements, and reviews the work. Then the factory creates a draft pull request.

<CardGrid stagger>
	<Card title="How work arrives" icon="pencil">
		Add the `vk` label to a GitHub issue to transfer work to the factory.
	</Card>
	<Card title="What you get back" icon="document">
		Receive a reviewed draft pull request with an execution run log in
		`docs/factory/`.
	</Card>
	<Card title="Human in the loop" icon="setting">
		Keep control of key decisions: review the draft PR, set it ready, and merge.
	</Card>
</CardGrid>
